# Аюулгүй байдлын сургалтын сайт

Ажилтнууд QR код уншуулаад орж, сургалтын бичлэгүүдийг үзэх энгийн сайт.

## Файлууд

- `index.html` — сайт өөрөө. Дээд хэсгийн `CONFIG` доторх нэр, лого, бичлэгүүдийг засна.
- `qr.html` — сайтын QR кодыг үүсгэж хэвлэх хуудас.
- `logo.png` — байгууллагынхаа логог энэ нэрээр нэмнэ.
- `videos/` — бичлэгээ файл хэлбэрээр хийх бол энд.

## GitHub Pages дээр байршуулах

1. GitHub дээр шинэ repository үүсгэнэ (жишээ нь `safety-training`), **Public** болгоно.
2. **Add file → Upload files** дарж энэ хавтсан доторх бүх файлыг чирч оруулаад **Commit changes** дарна.
3. **Settings → Pages** руу орно. *Source* хэсэгт **Deploy from a branch**, branch дээр **main** ба **/(root)** сонгоод **Save**.
4. 1–2 минутын дараа сайт `https://ТАНЫ-НЭР.github.io/safety-training/` хаягаар нээгдэнэ.
5. `https://ТАНЫ-НЭР.github.io/safety-training/qr.html` руу ороод QR кодоо хэвлэнэ.

## Бичлэг нэмэх

`index.html` доторх `videos:` жагсаалтад бичлэг бүрт гурвын нэгийг бөглөнө:

```js
{ title: "Галын аюулгүй байдал", duration: "6 мин",
  description: "Товч тайлбар",
  youtube: "https://youtu.be/XXXXXXXXXXX", drive: "", file: "" },
```

- **YouTube (зөвлөж байна)** — бичлэгээ *Unlisted* (Жагсаалтгүй) байршуулна. Хайлтаар гарахгүй, зөвхөн линктэй хүн үзнэ.
- **Google Drive** — файлын эрхийг *Anyone with the link* болгоод линкийг `drive:` дээр тавина.
- **Файл** — `videos/01.mp4` гэх мэт. GitHub нэг файлд 100MB хязгаартай тул богино, шахсан бичлэгт л тохиромжтой.

Шинэ бичлэг нэмэхэд доор нь дахиад нэг мөр хуулаад засахад болно. Засвараа GitHub дээр хадгалахад сайт хэдэн минутын дараа шинэчлэгдэнэ, QR код өөрчлөгдөхгүй.

## Анхааруулга

Public repository-г хэн ч харах боломжтой. Дотоод, нууц агуулгатай бичлэгийг сайтад бүү оруул.
